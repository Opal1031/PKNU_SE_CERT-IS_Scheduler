## 2. 분야와 내부 가중치

이 표는 개발자용입니다. 설문을 마친 뒤 결과 화면에서는 분야 이름과 쉬운 설명을 함께 보여 주세요.

| ID | 추천 분야 | 사용자용 설명 |
| --- | --- | --- |
| W | 웹 보안 | 사이트와 앱에서 이용 과정의 빈틈을 찾는 분야 |
| R | 리버싱 | 완성된 프로그램을 살펴 내부 작동 방식을 알아내는 분야 |
| S | 시스템 보안 | 프로그램의 작은 오류가 어떤 결과를 만드는지 실험하는 분야 |
| F | 디지털 포렌식 | 남아 있는 기록과 흔적으로 지난 일을 재구성하는 분야 |
| C | 암호학 | 수학적 규칙으로 정보를 보호하는 방법을 연구하는 분야 |

여기서 시스템 보안은 폭넓은 운영·관리 업무 전체가 아니라, **프로그램의 내부 오류를 탐구하는 입문 방향**으로 범위를 정했습니다. 다섯 분야는 전체 보안 분야를 모두 대표하지는 않습니다.
