# CERT-IS 화면별 작업 트리

2026-10-08 현재 코드 기준. `[구현]`은 브라우저 로컬 데모에서 동작한다는 뜻이며 서버 연결 완료를 의미하지 않음. 하위 항목은 페이지 안의 영역·팝오버·관리 창을 포함함.

```text
CERT-IS
├─ 1. 공통 프레임 [구현]
│  ├─ 사이드바: 홈 / 달력 / 예약 / AI 추천 / 설정
│  ├─ 점선 2줄 / 사이드바 접기·펼치기
│  ├─ 프로젝트·스터디 와플 팝오버
│  │  ├─ 프로젝트 / 스터디 구역 분리, 3열 아이콘 목록
│  │  └─ 검색 / 생성 / 이름 2줄 표시·잘릴 때 전체 이름 확인
│  ├─ 활동 생성: 유형 / 이름 / 분야 / 목표 / 기간 / 구성원
│  └─ 상단 현재 위치 / 사용자·임원진 미리보기
├─ 2. 홈 [현재 활동 목록 / 요약 홈은 보류]
│  ├─ 활동 검색 / 유형·분야·상태·팀장 필터 / 정렬
│  ├─ 팀장 / 내 역할 / 상태 / 다음 일정·마감 표시
│  └─ 보류: 내 활동·일정·최근 작업·D-day·최신 활동 종합 요약
├─ 3. 개인 달력 [구현]
│  ├─ 월간 / 목록 보기 / 이전·다음 달 / 오늘
│  ├─ 날짜 상세: 전체 일정 / 내 담당 필터
│  ├─ 일정 등록·상세·수정·삭제
│  │  └─ 기간·시각 / 공개 범위 / 담당자·업무 / 진행 상태
│  └─ 개인 즐겨찾기: 여러 핀 / 항상 표시 / 날짜 칸 높이 확장
├─ 4. 동아리방 예약 [구현]
│  ├─ 날짜 세로 / 시간 가로 / 날짜 추가 스크롤
│  ├─ 날짜 1(월) / 월 제목 고정·교체 / 시간 헤더 고정
│  ├─ 09~24시 전체 표시 / 30분 단위 / 예약자명 표시
│  ├─ 시작 날짜 이동 / 오늘 / 빈 칸에서 신청
│  └─ 예약 상세·변경·취소 / 중복·자정 초과 차단 / 취소 기록
├─ 5. AI 추천 [샘플 구현]
│  ├─ 관심 분야 / 경험 선택
│  ├─ 선택값별 예시 결과 / 관련 활동 이동
│  └─ 미구현: Gemini 연결·실제 AI 추천
├─ 6. 프로젝트·스터디 내부 [같은 화면 구조로 구현]
│  ├─ 활동 관리: 정보 수정 / 상태 / 구성원 / 팀장 위임 / 탈퇴
│  ├─ 팀 캘린더: 월간·목록 / 담당 필터 / 일정 관리
│  ├─ 회의록
│  │  ├─ 방별 문서 선택 / Markdown 편집·미리보기·나란히
│  │  ├─ 양식 추가 / 초안 복원·폐기 / 명시적 저장
│  │  └─ 버전 이력 / 최신본과 충돌 비교 / Markdown 내보내기
│  ├─ 활동 예약: 공통 시간표 / 해당 활동 예약 기록
│  └─ 채팅 패널 [참여 활동 안에서 표시]
│     ├─ 방 목록·검색·정렬 / 태그 필터 / 미확인 표시
│     ├─ 메시지 입력·로컬 전송 / 이전 메시지 / 메시지 검색
│     ├─ 대화 → 회의록 인용 / 채팅 폭 조절 / 독립 스크롤
│     └─ 방 생성·수정·보관·복원 / 태그·그룹 이름·순서·삭제
├─ 7. 설정 [구현]
│  ├─ 사용자·임원진 미리보기 / 화면 설정 초기화
│  ├─ 메시지 수신 예시 / 샘플 데이터 초기화
│  └─ 최근 변경 기록
└─ 8. 서버 연동 [미구현]
   ├─ 실제 로그인·인증 / API·DB / 개인 즐겨찾기 서버 저장
   └─ 실시간 채팅 / 여러 PC 동시 예약 보장
```

공통 프레임과 전역 페이지에서는 채팅 패널을 숨김. 개인 즐겨찾기는 사용자별 브라우저 저장이며 팀 캘린더에는 적용하지 않음. 프로젝트와 스터디는 별도 유형이지만 내부 페이지 구성은 공유함.

다음 검토 항목은 위 번호와 가지 이름으로 지정할 수 있음. 예: `6 → 회의록 → 나란히 보기`.
